这里是 **Bin9chn** 的研究与工程笔记，主要记录网络安全研究、CTF 赛题复现和安全工具开发。

关注方向包括协议安全、攻击面分析、本地优先的数据工具和密码学 CTF 工具链。相比只记录结论，更希望保留问题如何被发现、如何验证，以及最后怎样变成可靠实现的过程。

## 个人履历

- **凌日网络与信息安全团队创始人**，负责团队建设、技术方向与安全研究。
- 长期从事 Web 安全、协议安全、漏洞分析与应急响应研究，持续关注 CVE 和 HTTP/2 等方向。
- 持续参与 CTF 竞赛、题目复现与 WriteUP 输出，覆盖 Web、密码学、流量分析和 Misc。
- 开发并维护 LapCry、LRT CryptoCTF Tools 等安全工具，关注本地优先、可复现和低摩擦的工程实践。
- 持续在 GitHub 与 CSDN 发布技术文章、研究记录和开源项目。

## 当前项目

- [**LapCry**](https://github.com/Bin9chn/LapCry_public)：本地优先的桌面加解密数据处理工作台。
- [HTTP/2 Bomb](https://github.com/Bin9chn/http2-bomb)：HTTP/2 压缩放大与流控停滞研究。
- [LRT CryptoCTF Tools](https://github.com/Bin9chn/LRT-CryptoCTF-Tools)：面向 CTF 的密码学桌面工具。
