### 一、入门必懂：PHP基础特性与常见“坑”

PHP的弱 类 型特性、变量作用域以及内置函数的特殊行为，是CTF入门题中最常出现的考点。很多看似“无厘头”的题目，本质上都是对这些基础特性的考察。

#### 1\. 弱类型比较：==与===的天壤之别

PHP在使用“==”进行比较时，会先将两侧变量转换为相同类型再比较，而“===”则要求类型和值完全一致。这一特性常常成为出题的核心。

例如某道入门题的核心代码：

```php
<?php
$pass = $_GET['pass'];
if ($pass == 'ctf123' && $pass !== 'ctf123') {
    echo "flag{xxx}";
}
?>
```

这里看似矛盾的条件，利用弱类型比较即可破解。由于PHP中 字符串 与数字比较时会将字符串转换为数字，我们可以构造`pass=ctf123123`吗？不，更简单的是利用“0”的特性——当字符串以非数字开头时，转换为数字为0。不过这里更直接的思路是利用 数组 ：PHP中数组与字符串比较时，“==”会返回false，但如果构造`pass[]=1`，此时$pass是数组，与字符串'ctf123'用“==”比较为false，不对。哦，正确的构造应该是利用数字与字符串的转换，比如`pass=0ctf123`？不，再仔细看条件：$pass == 'ctf123'且$pass !== 'ctf123'。其实更简单的是，当$pass为数字123时，与字符串'ctf123'比较，PHP会将'ctf123'转换为数
