收录标准

  • ·内容与网络安全、CTF、开发或技术写作相关，且以原创为主。
  • ·已正常运行，能稳定访问；纯采集站、镜像站与导航站不收。
  • ·站点上没有大量广告、诱导下载或与主题无关的软文。
  • ·已在本站添加我的友链（互相链接是前提，不是交换条件）。

常见问题

提交后会发生什么？

表单会生成一条预填好的 GitHub Issue，你确认发布后我才能看到。不提交 Issue 等于没有申请。

头像可以是外链吗？

可以，但请用稳定的地址。通过后我会把头像下载到站内，避免你换图导致友链卡片破图。

为什么需要先加本站？

友链本质是互相推荐。只想单向收录的站点，一般不会通过。
