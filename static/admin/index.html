用 GitHub 账号验证

后台直接读写 Bin9chn/Bin9chn.github.io 仓库。只有该仓库所有者 Bin9chn 的 GitHub 凭证才能通过验证，其他账号会被拒绝。

怎么拿到 Token？
  1. 打开 GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens。
  2. Repository access 只勾选 Bin9chn.github.io。
  3. Permissions → Repository permissions → Contents: Read and write；Metadata 会自动带上只读。
  4. 生成后复制以 github_pat_ 开头的字符串，粘贴到上面。

Token 等同这个仓库的写权限，不要发给人、不要提交进仓库。换电脑或清除浏览器数据后需要重新粘贴。
